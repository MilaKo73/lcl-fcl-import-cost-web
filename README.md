# 해운 수입 비용·경로 시뮬레이터

LCL/FCL 수입 운송비와 구간별 경로를 검토하는 웹 대시보드입니다.

## 주요 기능

- LCL/FCL 운송 방식 및 컨테이너 규격 선택
- EXW 픽업지와 가까운 가상 메인항구 자동 지정
- 포장 치수 기반 CBM 및 R/T 계산
- HS CODE별 한국 기본 관세율 예시 표시
- 부산항 이후 FCL 안전운임 예시 계산
- 선택한 운송 방식의 비용 구성과 구간별 ROW DATA
- 향후 Excel 요율 업로드를 고려한 데이터 컬럼 구조

## 로컬 실행

```bash
pnpm install
pnpm run dev
```

브라우저에서 개발 서버가 표시하는 주소를 엽니다.

## 배포 빌드

```bash
pnpm run build
```

## 데이터 주의사항

현재 운임, 거리, 세율 및 안전운임 데이터는 기능 확인을 위한 가상 값입니다.
실제 계약과 수입 신고 전 최신 고시, 계약 요율 및 전문가 확인이 필요합니다.
